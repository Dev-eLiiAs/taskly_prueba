Una aplicación web moderna para la gestión de tareas y eventos, desarrollada con Flask y MySQL. Diseñada para ser intuitiva, eficiente y escalable.

## 🌟 Características

### ✨ Gestión de Tareas
- ✅ Crear, editar y eliminar tareas
- 📊 Estados: Pendiente, En progreso, Completada
- 🎯 Prioridades: Alta, Media, Baja
- 📅 Fechas de vencimiento
- 🔍 Filtros y búsqueda avanzada

### 📅 Gestión de Eventos
- 📝 Crear y administrar eventos
- 🗓️ Vista de calendario interactiva
- 📍 Ubicaciones y descripciones detalladas
- ⏰ Recordatorios automáticos

### 👥 Sistema de Usuarios
- 🔐 Autenticación segura
- 👤 Perfiles de usuario personalizables
- 🛡️ Roles: Organizador y Participante
- 🔒 Control de acceso basado en roles

### 📊 Dashboard y Reportes
- 📈 Estadísticas en tiempo real
- 📋 Resumen de tareas y eventos
- 🎨 Interfaz moderna y responsive
- 📱 Compatible con dispositivos móviles
